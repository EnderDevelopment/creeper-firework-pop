# Minecraft Creeper Firework Explosion Plugin

CreepyFireworkExplosion is a Minecraft plugin that replaces a creeper’s normal explosion with a firework effect. It creates a flickering, trailing ball firework with lime, pink, magenta, orange, and cyan colors; the firework is set to power 1.

## Install

1. Download the plugin JAR.
2. Place it in your Minecraft server’s `plugins` directory.
3. Start or restart the server.
4. Check the server log to confirm the plugin loads.

## Use

1. Join the server and let a creeper explode.
2. The normal creeper explosion is canceled and a multicolored firework is spawned at the creeper’s location.
